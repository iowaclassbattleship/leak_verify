Limitations
  • Marked cells are located by a keyed hash of the identifying column. If no identifying column survives, rows are matched back by another unique column or by the columns marking leaves alone.
  • Rounding below the marked digit destroys that layer. It only uses precision the data owner declared as noise.
  • Canary rows identify a recipient only if a sampled leak happens to contain one.
  • Canary rows are assembled from real rows with fresh identifying values, so they are plausible column by column but may combine attributes that rarely occur together.
  • Merged copies from several recipients are flagged, but not resolved.
